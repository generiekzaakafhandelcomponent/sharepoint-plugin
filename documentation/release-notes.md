# Release notes

Overzicht van wijzigingen per versie van de Sharepoint plugin.

## 1.1.0

In het SharePoint-tabblad van een zaak kun je nu een document uit de Documenten API naar SharePoint uploaden, een SharePoint-document opslaan in de Documenten API (waarna het uit SharePoint verdwijnt) en een SharePoint-document verwijderen. Met de nieuwe actie 'Verwijder document uit SharePoint' kan een proces, bijvoorbeeld na een formulier, een SharePoint-document verwijderen.
